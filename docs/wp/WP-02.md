## Automated checks

```bash
supabase start && supabase db reset
pnpm test:db
```

- `supabase/tests/00_tenancy_isolation.test.sql` — every `public` table has RLS, an org-scoped
  SELECT policy and no `anon` grants; a member (and a station) of org A sees **zero** org B rows
  in every table (tables are discovered from the catalog, so later WPs are covered
  automatically); cross-org writes are rejected; secret columns (`pin_hash`, `token_hash`) are
  unreadable.
- `01_next_seq` — formatting, per-org/per-kind numbering, cross-org guard.
- `packages/db/src/next-seq.db.test.ts` — **10 concurrent callers on separate connections get
  10 distinct, gap-free numbers**.
- `03_action_log` + `packages/db/src/with-action.db.test.ts` — **replaying an action id returns
  the stored result** without re-running; in-flight, abort, stale takeover, cross-org replay.
- `02_auth_hook` — claims for members, multi-org default, devices, inactive device/org.
- `04_devices_pins` + `packages/db/src/device-pairing.db.test.ts` — pairing through the Edge
  Function (single use, expiry, re-pair keeps the auth user), station claims, heartbeat,
  operator PIN + lockout, manager elevation, member invite.

## Pairing demo in `pnpm dev`

1. `supabase start && supabase db reset` (seeds org `demo-plant` with sites Main and Lodge).
2. Create `apps/web/.env.local` with `NEXT_PUBLIC_SUPABASE_URL` / `NEXT_PUBLIC_SUPABASE_ANON_KEY`
   from `supabase status`, and `NEXT_PUBLIC_APP_URL=http://localhost:3000`.
3. `pnpm db:demo-owner` — creates `owner@demo-plant.test` (set `KOVARIO_DEMO_PASSWORD`, or the
   script prints a random password once).
4. `pnpm dev`, sign in at `/login`.
5. `/admin/users`: set a PIN for Demo Owner (e.g. invite a staff member too — the invite mail
   lands in Mailpit at `http://127.0.0.1:54324`, its link opens `/auth/accept`).
6. `/admin/devices`: add a device, press **Pair** → QR + 8-character code (10 min, single use).
7. On the tablet (or a private window), scan the QR or open `/pair` and type the code → the
   tablet lands on `/device` signed in as `device-<id>@devices.kovario.internal`.
8. On `/device`: enter the operator PIN → operator shown; enter a manager PIN → "Approved by …
   until …" (token minted by the `elevate` Edge Function). `/admin/devices` shows last seen.
