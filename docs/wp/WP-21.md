# WP-21 — Reports and dashboards (#23)

`/reports` is available to owners/managers and linked from Admin. Five security-invoker
views retain the caller's tenant RLS. Pages and CSV use the same inclusive date/site
filters, including unassigned sites, and paginate daily aggregate rows beyond the API cap.

## Report definitions

| Report | Date basis (org timezone) | Measure |
|---|---|---|
| Daily volume | Intake date | Incoming lb by species; excludes drafts/cancellations |
| Pipeline | Intake date | Current intake counts/incoming lb for that intake cohort; not historical state |
| Throughput | Stage completion date | Average hours for complete, nonnegative consecutive timestamp pairs; sample count shown |
| Revenue | Linked payment approval date | Currently settled charges by kind, USD, excluding tax/tips/comped/voided charges; not a cash ledger or net-refund report |
| Reconcile variance | Reconcile date | Recorded expected/actual lb by species; percentage from summed weights, null at zero expected lb |

Revenue uses the source intake/storage intake site. Settlement charges use a site only
when all pooled intakes share one non-null site. Manual charges use the payment terminal
site. Missing or ambiguous sites stay unassigned; charges are never duplicated across sites.
No decision defaults were changed (DECISION-03 tenancy; DECISION-11 lb/USD).

## Upstream interface limitation

WP-12 currently records vessel weights but does not write `reconcile_line`. This report
consumes the documented `reconcile_line(intake_id, intake_line_id, expected_lb, actual_lb)`
interface, exercised with attributed measurements in the SQL tests. Until the reconcile
station persists those measurements, the variance panel is empty. It never invents species
attribution or substitutes the mutable vessel weight/release remainder. This dependency gap
needs a separate station change; WP-21 does not change station mutations.
